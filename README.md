# Boas Práticas em Java/Spring

Refatoração de API Spring Boot aplicando boas práticas de desenvolvimento Java.

> Para acompanhar a evolução do projeto e ver cada refatoração aplicada, consulte o [histórico de commits](../../commits/main).

## Práticas Aplicadas

- **Separação de responsabilidades** - Camada de Services para encapsular lógica de negócio
- **DTOs (Records)** - Transferência de dados desacoplada do modelo de domínio
- **Exceções customizadas** - Tratamento de erros específico do domínio
- **Strategy Pattern** - Validações extensíveis e independentes
- **Queries otimizadas** - Métodos específicos nos Repositories
- **Controllers enxutos** - Focados apenas na camada HTTP

## Tecnologias

- Java 17
- Spring Boot 3
- Maven
- MySQL
- Hibernate
- Flyway

## Baseado em

Projeto do curso [Boas Práticas de Programação com Java](https://www.alura.com.br) da Alura.

# Best Practices in Java/Spring

Refactoring a Spring Boot API applying Java development best practices.

> To follow the project evolution and see each refactoring applied, check the [commit history](../../commits/main).

## Applied Practices

- **Separation of concerns** - Service layer to encapsulate business logic
- **DTOs (Records)** - Data transfer decoupled from domain model
- **Custom exceptions** - Domain-specific error handling
- **Strategy Pattern** - Extensible and independent validations
- **Optimized queries** - Specific methods in Repositories
- **Lean controllers** - Focused only on HTTP layer

## Technologies

- Java 17
- Spring Boot 3
- Maven
- MySQL
- Hibernate
- Flyway
